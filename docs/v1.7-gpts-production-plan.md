# V1.7 GPTs Production Plan

## Goal

V1.7 finalizes the production GPTs integration and operations documentation. This stage is documentation-only. It must not change API logic, tax formulas, DB schema, production data, or test data.

## Current Baseline

- Latest code baseline: `7f80983 fix: parse full tax price index sheet`
- `main` and `origin/main` are in sync.
- V1.6 production validation completed.
- GPTs wrapper endpoints exist and are the production GPTs action path.

## Strict Non-Goals

Do not:

1. Modify land tax formula logic.
2. Re-import `tax_price_indexes`.
3. Call `POST /api/cpi/upload-excel`.
4. Clear production `public.tax_price_indexes`.
5. Add an `agents` table.
6. Touch `real-estate-card-api`.
7. Commit store credentials.
8. Commit session tokens.
9. Commit `ADMIN_UPLOAD_TOKEN`.
10. Commit full PDF download URLs.
11. Commit PDFs.
12. Commit test JSON files.
13. Write test tokens or full PDF download URLs into docs.

## Production GPTs Flow

GPTs production flow is:

1. `POST /api/gpts/login`
2. `POST /api/gpts/calculate`
3. `POST /api/gpts/prepare-pdf`
4. Present the short-lived `downloadUrl` to the user.

The GPTs Action Schema and GPTs Instructions must use `/api/gpts/*` endpoints as the primary flow.

## Legacy Endpoint Positioning

These endpoints remain backend/source APIs or human smoke-test tools:

- `POST /api/auth/login`
- `POST /api/land-tax/calculate`
- `POST /api/land-tax/pdf`
- `GET /api/land-tax/pdf/download`

GPTs production instructions should not direct GPTs to call them as the normal action path.

## OpenAPI Requirements

`docs/gpts-openapi-schema.yaml` must confirm:

- server URL is `https://land-tax-calculator-xi.vercel.app`
- operation IDs:
  - `gptsLogin`
  - `gptsCalculate`
  - `gptsPreparePdf`
- `prepare-pdf` response includes:
  - `success`
  - `data.downloadUrl`
  - `data.expiresInMinutes`
  - `data.storeProfileSummary`
  - `nextAction`
- GPTs is not required to parse binary PDF.

## GPTs Instructions Requirements

`docs/gpts-instructions-draft.md` should be directly usable as GPTs Instructions.

It must state:

- GPTs is the main interaction entrypoint.
- API is the source of truth for calculation and PDF preparation.
- GPTs must not replace the formula.
- GPTs must not trust user-entered store disclosure data.
- Login must use wrapper endpoint.
- Calculate must use wrapper endpoint.
- PDF preparation must use wrapper endpoint.
- Download URL is short-lived and must not be stored.
