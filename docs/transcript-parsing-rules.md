# 土地登記謄本判讀規則

本文件整理土地增值稅試算 GPTs 判讀土地登記謄本時應遵守的完整規則。GPTs Instructions 內也應保留精簡但完整的核心規則，不能只連到本文件。

## 一、核心原則

GPTs 判讀土地登記謄本時，必須依欄位名稱與相對位置判斷，不可只看數字大小或只抓第一個出現的金額。

土地增值稅試算需要的謄本資料主要是：

1. 土地面積
2. 權利範圍
3. 前次移轉年月
4. 前次移轉現值或原規定地價
5. 公告土地現值年月
6. 公告土地現值

不得要求使用者提供「本次移轉年月」。對使用者顯示時，請使用「公告土地現值年月」，不要使用「本次移轉年月」。

## 二、謄本中的 `****` 判讀規則

謄本中的 `****` 通常是固定格式標記，不一定代表資料遮蔽或缺漏。

判讀時不可因為出現 `****` 就判定無法辨識。

遇到以下格式：

```text
民國115年01月****公告土地現值：****1,900元／平方公尺
```

正確判讀：

```text
公告土地現值年月：115年01月
公告土地現值：1,900 元／平方公尺
```

遇到以下格式：

```text
115年01月****304.0元／平方公尺
```

若該行屬於「當期申報地價」，則只能判讀為當期申報地價，不可拿來當公告土地現值或前次移轉現值。

## 三、公告土地現值判讀規則

公告土地現值應從謄本上的「公告土地現值」欄位判讀。

範例：

```text
民國115年01月****公告土地現值：****1,900元／平方公尺
```

正確判讀：

```text
公告土地現值年月：115年01月
公告土地現值：1,900 元／平方公尺
```

判讀規則：

1. 先定位「公告土地現值」文字。
2. 同一行出現的民國年月，判讀為公告土地現值年月。
3. 「公告土地現值」後方或同一行 `****` 後方的金額，判讀為公告土地現值。
4. 不得使用「當期申報地價」代替公告土地現值。
5. 不得使用登記日期、買賣日期、送件日期或本次移轉時間代替公告土地現值年月。
6. 若找不到公告土地現值年月，應要求使用者補充「公告土地現值欄位所示的民國年月與金額」，不可自行用登記日期推算。

## 四、當期申報地價判讀規則

當期申報地價不是土地增值稅試算的本次公告土地現值。

若謄本同時出現：

```text
公告土地現值：****1,900元／平方公尺
當期申報地價：115年01月****304.0元／平方公尺
```

正確判讀：

```text
公告土地現值：1,900 元／平方公尺
當期申報地價：304.0 元／平方公尺
```

土地增值稅試算應使用：

```text
公告土地現值：1,900 元／平方公尺
```

不得使用：

```text
當期申報地價：304.0 元／平方公尺
```

作為本次公告土地現值。

## 五、前次移轉現值或原規定地價判讀規則

當謄本出現：

```text
前次移轉現值或原規定地價：
```

該欄位的有效年月與金額通常位於下一行。

判讀規則：

1. 先定位文字「前次移轉現值或原規定地價：」。
2. 往下一行讀取「民國年月 + **** + 金額元／平方公尺」格式。
3. 下一行的民國年月，判讀為前次移轉年月。
4. 下一行 `****` 後方的金額，判讀為前次移轉現值或原規定地價。
5. 不得讀取上一行「當期申報地價」的金額。
6. 不得把當期申報地價誤判為前次移轉現值。
7. 若下一行無法判讀，應要求使用者補充前次移轉年月與前次移轉現值，不可自行猜測。

範例：

```text
當期申報地價：115年01月****304.0元／平方公尺
前次移轉現值或原規定地價：
102年10月****1,619.6元／平方公尺
```

正確判讀：

```text
當期申報地價：304.0 元／平方公尺
前次移轉年月：102年10月
前次移轉現值或原規定地價：1,619.6 元／平方公尺
```

錯誤判讀：

```text
前次移轉現值：304.0 元／平方公尺
```

## 六、土地增值稅不得參考本次移轉時間

土地增值稅試算不得以以下欄位作為公告土地現值年月：

```text
本次移轉時間
登記日期
買賣日期
送件日期
所有權移轉登記日期
登記原因為買賣的日期
```

範例：

```text
登記日期：民國102年11月06日
登記原因：買賣
```

不得把 `102年11月` 當成公告土地現值年月，也不得稱為本次移轉年月。

正確方式：

1. 公告土地現值年月：讀「公告土地現值」同一行的民國年月。
2. 公告土地現值：讀「公告土地現值」欄位的金額。
3. 前次移轉年月與前次移轉現值：讀「前次移轉現值或原規定地價：」下一行。

## 七、使用者提示語規則

GPTs 登入成功後，如果資料不足，不得列出：

```text
本次移轉年月
```

應改列：

```text
公告土地現值年月
公告土地現值（元／平方公尺）
```

如果使用者有土地登記謄本，應提示：

```text
若您有土地登記謄本，也可以直接上傳，我可以協助判讀土地面積、權利範圍、公告土地現值、前次移轉年月與前次移轉現值。
```

不得出現以下問題句：

```text
是／否：這次是否延續先前已登入或已提供土地資料的案件？
```

請改成內部邏輯，不要詢問使用者：

1. 若本次對話已有成功登入狀態與已確認土地資料，可在本次對話流程中延續使用。
2. 若資料不足，直接列出缺少欄位。
3. 不要要求使用者理解 session、案件延續、流程狀態等內部概念。

## 八、缺少資料清單建議格式

```text
登入成功。接下來請提供土地資料，或直接上傳土地登記謄本，我可以協助判讀。

需要的資料如下：
- 土地面積（平方公尺）
- 權利範圍，例如 1/1、1/2
- 公告土地現值年月
- 公告土地現值（元／平方公尺）
- 前次移轉年月
- 前次移轉現值或原規定地價（元／平方公尺）

注意：不需要提供本次移轉日期、買賣日期或登記日期。
```

如果已上傳謄本，GPTs 應先判讀，不要重複要求使用者填寫已可從謄本取得的欄位。
