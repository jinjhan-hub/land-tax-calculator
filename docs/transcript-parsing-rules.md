# 土地登記謄本判讀規則

本文件整理土地增值稅 GPTs 判讀土地登記謄本時應遵守的規則。GPTs Instructions 仍需保留核心規則，不能只引用本文件。

## 一、核心原則

GPTs 判讀土地登記謄本時，必須依欄位名稱與相對位置判斷，不可只看數字大小或只抓第一個出現的金額。

土地增值稅試算需要的謄本資料主要是：

1. 土地面積
2. 權利範圍
3. 前次移轉年月
4. 前次移轉現值或原規定地價
5. 公告土地現值年月
6. 公告土地現值

不得要求使用者提供「本次移轉年月」。對使用者顯示時，請使用「公告土地現值年月」，不要使用「本次移轉年月」。

## 二、標題列行政區、地段、地號

若謄本標題列出現：

```text
北斗鎮新生段 0318-0000地號
```

應判讀為：

```text
行政區：北斗鎮
地段：新生段
地號：0318-0000
```

若同頁可見：

```text
彰化縣北斗地政事務所
```

可用於輔助判斷縣市為：

```text
彰化縣
```

因此可組成：

```text
landCityDistrict：彰化縣北斗鎮
landSection：新生段
landNumber：0318-0000
```

注意：

1. 可以用同頁地政事務所、地址或明確縣市文字輔助判斷縣市。
2. 不可無根據亂猜縣市。
3. 若只有「北斗鎮」但沒有任何縣市來源，可先填行政區「北斗鎮」，或要求使用者補充縣市。

## 三、權利範圍

謄本中：

```text
權利範圍：全部
```

應可轉換為：

```text
ownershipRange：1/1
```

或至少原樣帶入 PDF 顯示為：

```text
全部
```

不得空白。

## 四、謄本中的 `****` 判讀規則

謄本中的 `****` 通常是固定格式標記，不一定代表資料遮蔽或缺漏。判讀時不可因為出現 `****` 就判定無法辨識。

遇到以下格式：

```text
民國115年01月****公告土地現值：****1,900元／平方公尺
```

正確判讀：

```text
公告土地現值年月：115年01月
公告土地現值：1,900 元／平方公尺
```

遇到以下格式：

```text
115年01月****304.0元／平方公尺
```

若該行屬於「當期申報地價」，則只能判讀為當期申報地價，不可拿來當公告土地現值或前次移轉現值。

## 五、公告土地現值判讀規則

公告土地現值應從謄本上的「公告土地現值」欄位判讀。

範例：

```text
民國115年01月****公告土地現值：****1,900元／平方公尺
```

正確判讀：

```text
公告土地現值年月：115年01月
公告土地現值：1,900 元／平方公尺
```

判讀規則：

1. 先定位「公告土地現值」文字。
2. 同一行出現的民國年月，判讀為公告土地現值年月。
3. 「公告土地現值」後方或同一行 `****` 後方的金額，判讀為公告土地現值。
4. 不得使用「當期申報地價」代替公告土地現值。
5. 不得使用登記日期、買賣日期、送件日期或本次移轉時間代替公告土地現值年月。
6. 若找不到公告土地現值年月，應要求使用者補充「公告土地現值欄位所示的民國年月與金額」，不可自行用登記日期推算。

## 六、當期申報地價判讀規則

當期申報地價不是土地增值稅試算的本次公告土地現值。

若謄本同時出現：

```text
公告土地現值：****1,900元／平方公尺
當期申報地價：115年01月****304.0元／平方公尺
```

正確判讀：

```text
公告土地現值：1,900 元／平方公尺
當期申報地價：304.0 元／平方公尺
```

土地增值稅試算應使用：

```text
公告土地現值：1,900 元／平方公尺
```

不得使用：

```text
當期申報地價：304.0 元／平方公尺
```

作為本次公告土地現值，也不得作為前次移轉現值。

## 七、前次移轉現值或原規定地價判讀規則

當謄本出現：

```text
前次移轉現值或原規定地價：
```

該欄位的有效年月與金額通常位於下一行。

判讀規則：

1. 先定位文字「前次移轉現值或原規定地價：」。
2. 往下一行讀取「民國年月 + `****` + 金額元／平方公尺」格式。
3. 下一行的民國年月，判讀為前次移轉年月。
4. 下一行 `****` 後方的金額，判讀為前次移轉現值或原規定地價。
5. 不得讀取上一行「當期申報地價」的金額。
6. 不得把當期申報地價誤判為前次移轉現值。
7. 若下一行無法判讀，應要求使用者補充前次移轉年月與前次移轉現值，不可自行猜測。

範例：

```text
當期申報地價：115年01月****304.0元／平方公尺
前次移轉現值或原規定地價：
102年10月****1,619.6元／平方公尺
```

正確判讀：

```text
當期申報地價：304.0 元／平方公尺
前次移轉年月：102年10月
前次移轉現值或原規定地價：1,619.6 元／平方公尺
```

錯誤判讀：

```text
前次移轉現值：304.0 元／平方公尺
```

## 八、土地增值稅不得參考本次移轉時間

土地增值稅試算不得以以下欄位作為公告土地現值年月：

```text
本次移轉時間
登記日期
買賣日期
送件日期
所有權移轉登記日期
登記原因為買賣的日期
```

範例：

```text
登記日期：民國102年11月06日
登記原因：買賣
```

不得把 `102年11月` 當成公告土地現值年月，也不得稱為本次移轉年月。

正確方式：

1. 公告土地現值年月：讀「公告土地現值」同一行的民國年月。
2. 公告土地現值：讀「公告土地現值」欄位的金額。
3. 前次移轉年月與前次移轉現值：讀「前次移轉現值或原規定地價：」下一行。

## 九、PDF 產製前資料規則

呼叫 `gptsPreparePdf` 前，需確認：

1. 已有 calculate 結果。
2. 已有名片或聯絡資訊。
3. 已有 PDF 顯示用土地基本資料：
   - 縣市/行政區
   - 地段
   - 地號
   - 土地面積
   - 權利範圍

若缺少上述資料，不得呼叫 `gptsPreparePdf`，應先要求使用者補充。不得生成土地基本資料空白的 PDF。

## 十、使用者提示語規則

GPTs 登入成功後，如果資料不足，不得列出：

```text
本次移轉年月
```

應改列：

```text
公告土地現值年月
公告土地現值（元／平方公尺）
```

不得詢問：

```text
是否延續先前案件
是否有未顯示在目前對話中的案件
是否沿用上一筆資料
```

請改成內部邏輯：

1. 若本次對話已有成功登入狀態與已確認土地資料，可在本次對話流程中延續使用。
2. 若資料不足，直接列出缺少欄位。
3. 不要要求使用者理解 session、案件延續、流程狀態或隱藏上下文。
